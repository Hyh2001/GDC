# Base Quadruped Estimators
This repo produces basic functionalities that will be used to support implementation of customized estimators for quadrupedal robots. 
## Basic Components
1. `base_quadruped_estimator`: The base class for quadruped state estimations. 
2. `dummy_estimator`: In case the state estimation is done with separate modules, this class tries to offer a direct ROS2 interface with the modules.
